# THE TIMES

Website for **THE TIMES** (*Transient Inference & Modelling of Extreme Systems*), a weekly meeting at the Institute of Astronomy, Cambridge, organised by Nikhil Sarin and James Alvey.

It's a plain static site: HTML, CSS and a little JavaScript. There's no build step. Open `index.html` in a browser, or serve it locally:

```bash
python3 -m http.server 8000   # then visit http://localhost:8000
```

## Pages

| Page | File | Content from |
|---|---|---|
| Home | `index.html` | `data/schedule.js` (next meeting), `data/papers.js` (latest 4) |
| Research | `research.html` | edit the HTML directly |
| People | `people.html` | `data/members.js` |
| Meetings | `meetings.html` | `data/site.js`, `data/schedule.js` |
| Papers | `papers.html` | `data/papers.js` |
| Software | `software.html` | `data/software.js` |

The header, footer and all lists are generated by `assets/js/site.js` from the files in `data/`. To update the site you normally only edit `data/`.

## Common edits

**Add a member.** Copy the template at the top of `data/members.js` into `TIMES.members`. For a photo, put a square image in `assets/img/people/` and set `photo: "assets/img/people/name.jpg"`. Without a photo, the person's initials are shown.

**Add a paper.** Add an entry at the top of `TIMES.papers` in `data/papers.js`. Group members' names are bolded automatically. To find candidates:

```bash
python3 scripts/arxiv_candidates.py          # new arXiv papers by everyone in members.js
```

The script prints entries ready to paste. It skips papers already listed and papers with more than 50 authors. Check each one is in scope and add tags before pasting.

**Fill in the schedule.** In `data/schedule.js`, set `format` (`"talk"`, `"journal"`, `"roundtable"`), `speaker` and `title` for each date. Past dates are dimmed and the next meeting appears on the home page.

**Add software.** Add an entry to `TIMES.software` in `data/software.js`. Use `status: "soon"` for tools that aren't public yet.

**Change time, room, Slack or contacts.** Edit `data/site.js`.

## Deploying on GitHub Pages

1. Push to `main` on `github.com/nikhil-sarin/times_group`.
2. In the repo, go to **Settings → Pages**, set **Source** to *Deploy from a branch*, then choose `main` and `/ (root)`.
3. The site appears at `https://nikhil-sarin.github.io/times_group/`.

`.nojekyll` is included so GitHub serves the files as they are.
